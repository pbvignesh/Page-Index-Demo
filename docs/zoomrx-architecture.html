The full system — Data Archive Copilot & Agentic MR

architecture overview

An applied-AI platform for pharma market research. Multi-tenant on AWS, each client tenant isolated in its own database, FastAPI backend, durable jobs on Temporal, LLMs via Anthropic Claude.

This is the production system that the public demo repo distills — the demo is a faithful, runnable miniature of the same ideas (a reasoning-based retrieval tree, skill-driven analysis, a sandbox for model-written code, and a grounding gate).

2Two products

Data Archive Copilot

retrieve · reason · cite
  • Answers over ~10 years of a client's research — structured (survey/quant) and unstructured (decks, reports, qual transcripts).
  • A lead agent fans out to skill-loaded sub-agents, each composed from skills (prompt modules) + a scoped set of tools from the registry.
  • Retrieval + reasoning produce cited answers — every claim traces to a survey question/response or a document passage.
  • Regulated data means trust is the hard part; answers are gated by evals before they ship.
  • Turns weeks of manual analysis into hours.

Agentic MR

analyze · compute · artifact
  • Agentic analysis over structured survey data (per-respondent quant + qual).
  • The agent selects the right analysis skill and computes real metrics — Top-2-Box, message recall, segment cross-tabs, significance / low-base guards.
  • Produces artifacts: tables, charts, insights. Also powers personas and message testing.
  • A routing layer turns a natural-language question into the right structured query.
  • An enrichment layer tags the data so the agent can find and route correctly.

3What makes it hard — the last mile

Grounding & citationsEvery claim traceable on regulated data — no unsourced numbers.
Self-improving evalsAuto-generated suites, LLM-as-judge for faithfulness, reproducibility gates.
Untrusted model codeThe agent writes analysis code — it must run safely, boxed, no credentials.
Durable orchestrationRetries, idempotency, human-in-the-loop across long jobs (Temporal).
Multi-tenant isolationOne client's data never crosses into another; DB-per-tenant.

The code sandbox. The agent's analysis code runs in an isolated container (gVisor / Docker), no network, no credentials, with content-addressed durable working state, atomic save, and filesystem-containment defenses. The demo's Docker sandbox is a small version of exactly this.
