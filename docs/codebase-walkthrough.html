Filing Copilot — how it's built

codebase walkthrough

A small agent over SEC filings that decides, per question, between two capabilities. Ingest a company's 10-K once; then ask questions in plain English and get a cited answer or a computed artifact back.

RETRIEVE

Reasoning-based navigation

Walks a PageIndex tree of the filing's Items (vectorless RAG), lands on the relevant section, and answers from its narrative text — with a citation back to the Item.

ANALYZE

Skill-driven computation

Picks a structured dataset + an analysis skill, the model writes pandas, it runs in an isolated Docker sandbox, and returns a computed artifact (table) cited to the source financials.

4Two design ideas worth pointing at

⛨

The sandbox — running untrusted code safely

Model-authored pandas is real code, so it runs boxed in sandbox.py:

  • --network none — no egress
  • --memory 512m --cpus 1 --pids-limit 128
  • non-root user, read-only mount (/work:ro)
  • hard timeout; only a JSON result line comes back
≡

Skills are files — not code

Each analysis is a markdown how-to in skills/ (method + guardrails + output contract). The router offers it automatically — adding an analysis = adding a file, no code change.

margin_analysis yoy_growth ratio_analysis common_size guardrails
